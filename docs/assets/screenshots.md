# README 화면 캡처

`desktop.png`와 `mobile.png`는 몽글터미널 v0.3.5의 실제 웹 UI와 실제 Windows PowerShell을 사용해 촬영한 화면입니다. 픽셀 편집, 앱 화면의 DOM 교체, 상태 응답 조작은 하지 않았습니다.

| 이미지 | 캡처 조건 |
| --- | --- |
| `desktop.png` | Chrome 1440 × 900, 어두운 테마, 3개 분할 영역·4개 셸. 첫 영역에 독립된 탭 두 개와 마지막 탭 뒤 + |
| `mobile.png` | Chrome 모바일 에뮬레이션 390 × 844, 12px 글꼴, 같은 호스트의 첫 번째 터미널 |

터미널 내용은 README를 위한 **예시 프로젝트**입니다. 화면의 테스트 2개는 예시 프로젝트의 패널 추가·그룹 이름 변경 함수를 실제 Node 테스트 러너로 실행한 결과이며, 몽글터미널 전체 회귀 검사 결과를 나타내지 않습니다. 모바일 이미지는 반응형 화면 설명용입니다. 실제 휴대폰, 소프트 키보드, Tailscale 통신을 검증했다는 의미는 아닙니다.

## 다시 촬영하기

Windows, Node.js 24, Chrome, 설치된 PowerShell이 필요합니다.

```powershell
npm ci
npm run build
npx tsx scripts/capture-readme.ts
```

스크립트는 `.test-data/readme-demo/` 아래에 새 호스트 데이터와 예시 프로젝트를 만듭니다. 개인 경로 노출을 피하기 위해 비어 있는 드라이브 문자를 잠시 매핑하며, 화면에는 `X:\workspace` 같은 예시 경로가 표시됩니다. 그룹 생성·이름 변경·분할·화면 설정은 실제 UI로 수행하고, 호스트의 실제 터미널 처리·입력·출력·제어권 흐름을 사용합니다. 브라우저와 호스트 사이 연결만 로컬 테스트 브리지로 연결합니다.

PowerShell은 `-NoProfile`로 실행하고 명령 기록 저장을 끕니다. 기존 사용자 호스트·셸·인증 데이터·Tailscale 설정을 사용하지 않습니다. 종료 시 자신이 만든 브라우저와 호스트를 닫고, 소유한 드라이브 매핑과 이번 실행의 격리 폴더만 확인 후 제거합니다.

2026-10-01에 0.3.5의 **새 터미널** 버튼 이름에 맞춰 재생성했습니다. 0.3.4 촬영에서 정리한 영역별 탭과 모바일 설정 조작을 사용합니다. 검증 결과는 [0.3.5 배포 기록](../validation/public-release-0.3.5.md)에 정리합니다.
