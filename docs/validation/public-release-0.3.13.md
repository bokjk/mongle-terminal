# 0.3.13 미배포 태그 검증

**공개하지 않았다.** 제품 검사는 통과했지만 파일 보존 실패로 태그 작업이 실패했다. 아래 준비 기록과 구분하며 [0.3.14 후속 배포](public-release-0.3.14.md)로 이어간다.

## 배포 준비

2026-10-07. 사용자 요청으로 CLI 드래그 입력 보존·Shift 자동 복사와 모바일 전체화면 터치 스크롤을 0.3.13으로 배포 준비한다. 현재 공개 배포는 0.3.12이며 최종 게시·익명 다운로드 확인 전에는 배포 완료로 표시하지 않는다.

## 기능 검증

- 제품 코드 `ec5ac59`와 같은 최종 수정본 `1677690`의 전체 Windows CI: 회귀 452 통과·실패 0·선택 실행 15 생략, 별도 네이티브 클립보드·업데이트 브리지 2/2, 실제 NSIS 전체 파일 일치·교체·작업 복원 통과.
- [데스크톱 Claude 검사](claude-native-selection.md), [Codex 검사](codex-native-selection.md): 실제 몽글 앱의 드래그·복사. Claude 안내가 가린 글자 누락은 사용자에게 설명하고 허용된 알려진 제약으로 남겼다.
- [모바일 검사](mobile-cli-scroll.md): gpt-6-astra가 실제 Claude·Codex PTY에 연결해 Chrome 모바일 에뮬레이션의 trusted touch 양방향 이동, 포커스 유지, Codex Ctrl·Alt ON 스크롤을 확인했다. 실물 휴대폰 검사로 표현하지 않는다.
- 실사용 세션·인증·Tailscale Serve는 변경하지 않았다. 새 모델 요청 없이 합성 대화를 사용했다.

## 게시 전 확인

버전 PR·dev→main 배포 PR의 Windows 검사와 대상 정책을 확인한다. 최종 main 태그에서 회귀·패키징·네이티브·NSIS 실제 교체·복원을 통과한 windows-release artifact만 사용한다. 검증된 공개 초안의 5개 첨부와 메타데이터를 대조하고, 게시 뒤 인증 없는 전체 다운로드·해시와 실제 Electron 업데이트 다운로드를 확인한다.

## 남은 검증 범위

실물 휴대폰·OS 키보드·외부 Tailscale 네트워크 및 모든 CLI 버전은 전수 검사하지 않았다. 사용자와 합의한 모바일 검증 기준은 Chrome 모바일 에뮬레이션이다. Claude 자체 안내와 겹친 글자의 복사 누락은 남아 있다. 이 PC의 사용 중인 설치본은 배포 작업으로 자동 교체하지 않는다. 소스 비공개·라이선스·코드 서명 상태는 유지한다.

## 기능 PR 최종 검사와 저장 공간 재시도

`c4055f2`의 Windows 검사 [37510826807](https://github.com/bokjk/mongle-terminal/actions/runs/37510826807)는 회귀 454 통과·실패 0·선택 실행 15 생략 및 별도 네이티브 2/2를 통과했다. 실제 NSIS 교체·전체 파일 일치·작업 복원 [37510826836](https://github.com/bokjk/mongle-terminal/actions/runs/37510826836)도 통과했다. PR #44를 dev에 병합하고 배포 PR #45를 열었다.

과거 대형 CI 사본 11개의 백업·자체 체크섬 대조·정리를 완료해 남은 Actions artifact는 72개·80,037바이트였다. 공개 배포 파일과 태그는 그대로 보존했다. 정리 후 이전 실행 37508596242의 재시도도 artifact quota로 실패했으므로 즉시 업로드가 복구됐다고 판단하지 않는다. 검사를 모두 통과한 최종 태그 파일을 비공개 소스 릴리스 초안에 보존하는 경로를 추가한다. 실제 태그 보존·공개 게시 결과는 완료 후 별도로 기록한다.

## CI 저장 공간 오류와 보존 보완

후보 dab5f8f의 Windows 검사 37508596242는 타입·빌드·네이티브 통과 뒤 artifact quota 오류로 실패해 전체 회귀를 실행하지 못했다. 실제 설치 검사 37508596131도 NSIS 교체·파일 일치·작업 복원은 통과했지만 결과 업로드에서 같은 오류가 났다. 두 실행을 전체 CI 통과로 세지 않는다.

기존 공개 0.3.1~0.3.12의 배포용 CI 사본 11개(0.3.9 제외)를 로컬 백업하고 6개 파일·자체 체크섬을 확인하고 공개 5개 첨부와 대조한 뒤 CI 사본만 정리한다. 0.3.10 이후는 공개 파일과 일치한다. 0.3.8 등 초기 배포는 공개 로컬 산출물과 태그 CI 재빌드가 다른 이력이 있으므로 차이를 별도 기록하고, CI 원본 전체 백업·자체 체크섬을 보존한다. 공개 파일을 CI 재빌드로 교체하지 않는다. 공개 Release·태그·실행 로그·작은 검사 결과는 보존한다. 백업·정리 영수증은 무시된 .test-data에 보존한다.

작은 네이티브/설치 결과를 로그와 summary에도 허용 필드·원본 JSON SHA-256으로 기록하고, 진단 artifact 업로드만 선택적 보존으로 변경했다. 실제 검사와 필수 결과 기록은 계속 실패 시 CI를 중단하며 최종 배포 파일 보존은 필수다. 큰 windows-release 보존 기간은 1일로 줄여 중복 누적을 줄인다. 관련 결과 누락·실패·정리 실패·개인 필드 제외 검사 2개와 타입 검사를 통과했다. 전체 CI·태그 검사에서 다시 확인한다.


## 최종 태그 실패 기록

소스 태그 v0.3.13은 main `ff2f80d659d7a9ada0235cc4e4b731616effb484`이며 이동하거나 덮어쓰지 않는다. [태그 실행 37517601567](https://github.com/bokjk/mongle-terminal/actions/runs/37517601567)은 회귀 456 통과·실패 0·선택 14 생략, 최종 패키지 네이티브 2/2 및 실제 NSIS 교체·전체 파일 일치·작업 복원을 통과했다. Actions artifact quota와 비공개 초안 생성 직후 조회 실패 때문에 파일 보존 및 최종 storage gate가 실패했다. 이 실행을 전체 배포 성공으로 세지 않는다.

비공개 소스 draft 405074793은 생성됐지만 첨부는 0개다. published 릴리스로 판단된 것이 아니라, 생성 직후 조회 결과가 null일 때 같은 오류 메시지를 쓰고 즉시 중단하는 결함을 재현했다. 저장한 실제 조회 응답에서는 정상 draft를 찾았으므로 당시 GitHub 반영 지연은 유력 가설이며 확정하지 않는다. 실제 응답 형식과 빈 조회·지연 후 조회·지속 누락·published/mixed 거부를 추가 검증한다. 공개 저장소에 v0.3.13은 게시하지 않았다.

후속 조사에서 [GitHub CLI #5252](https://github.com/cli/cli/issues/5252)의 자동화 토큰 REST 목록 draft 누락 사례를 확인했다. 개인 인증으로 저장한 응답의 통과는 CI 토큰의 동일 동작을 증명하지 않는다. 0.3.14에서는 초안 발견을 GraphQL로 변경하고 ID 응답을 대조하며, 실제 CI 토큰의 읽기 검사를 먼저 수행한다.
