# 휴대폰 컴퓨터 전환

2026-10-10, Windows x64, 미배포. 휴대폰 브라우저에서 같은 Tailscale의 다른 몽글 PC로 바로 전환할 수 있게 했다.

## 배경

컴퓨터 선택 메뉴는 데스크톱 앱에서만 동작했다. 휴대폰 화면은 각 PC가 직접 보내 주는 웹페이지라 PC마다 주소를 따로 열어야 했다. 사용자는 두 PC를 휴대폰에서 주소를 바꿔 가며 쓰고 있었고, 휴대폰에서 목록으로 고르기를 원했다. 앞서 0.3.19에서 휴대폰으로 새 기기를 승인하는 기능을 먼저 만들었고, 이번에 휴대폰 목록을 만들었다.

## 설계 판단

- 브라우저 인증은 origin(쿠키·CSP `connect-src`·Origin 검사)에 묶여 있어 한 페이지에서 다른 PC에 접속할 수 없다. 이 경계를 그대로 두고, 고른 PC 주소로 최상위 이동만 한다. 각 PC가 자기 주소에서 이 브라우저의 승인을 다시 확인한다.
- 휴대폰 브라우저의 저장 공간도 주소마다 따로라서, 휴대폰에 저장한 목록은 PC를 옮기면 보이지 않는다. 그래서 목록은 지금 연 PC의 호스트가 Tailscale에서 찾아 준다. 두 PC 모두 새 버전이면 어느 쪽에서든 서로를 찾는다. 한 PC가 다른 PC를 중계하는 방식과 PC끼리 미리 등록하는 방식은 쓰지 않았다.
- Tailscale 접근 규칙이나 꺼진 PC처럼 찾지 못하는 경우를 위해 휴대폰에서 주소를 직접 추가할 수 있다. 이 목록은 그 브라우저의 해당 PC 주소에만 저장된다.

## 변경

- 다른 PC 찾기(`packages/host/computers.ts`): `tailscale status --json`에서 같은 사용자의 온라인 Windows 기기를 고르고 공유·태그 기기는 뺀다(최대 32대). 각 기기의 Tailscale IPv4로 접속하되 SNI·인증서 검증·Host 헤더는 MagicDNS 이름을 써서 443·8443·10000 포트의 `GET /health`만 요청한다. 몽글 health 형식일 때만 인정하고, 앞 순서 포트에서 찾으면 나머지 포트를 기다리지 않는다. 결과는 60초 재사용하고 다시 찾기는 5초가 지난 결과만 새로 찾는다. 자기 자신은 hostId로 뺀다.
- Tailscale 실행(`packages/host/remote.ts`): CLI 실행과 오류 안내를 `runTailscale`로 분리해 원격 설정과 찾기가 같이 쓴다. 원격 설정의 동작은 바꾸지 않았다.
- 게이트웨이(`packages/host/gateway.ts`): 인증된 WebSocket 세션의 `computers.list`를 직접 처리하고 core로 보내지 않는다. 매개변수는 `refresh`만 받고 기기당 분당 30회로 제한한다. 검색은 네트워크를 기다리므로 응답을 나중에 보내, 같은 연결의 터미널 입력 등 다른 요청이 막히지 않게 했다.
- 화면: 데스크톱 앱이 아닌 브라우저에서는 컴퓨터 이름이 **컴퓨터 전환** 버튼이 된다(`apps/web/src/ComputerSwitcher.tsx`). 창은 열린 메뉴 바깥(문서 본문)에 띄운다. 주소 검사·저장·목록 합치기는 `apps/web/src/computer-list.ts`로 분리했다. 공용 창 컴포넌트는 `apps/web/src/Modal.tsx`로 옮겼다.
- 개발 중 고친 점: 처음 구현은 응답하지 않는 포트의 시간 제한(2.5초)까지 기다렸다. 실제 확인에서 이를 발견해 포트 순서대로 결과를 받도록 고쳤다. 또 PC를 누르면 그 버튼을 비활성화해 초점이 창 밖으로 빠졌고, Esc로 창이 닫히지 않았다. 버튼은 `aria-disabled`로 바꿔 초점을 유지하고 중복 누름은 무시한다.

## 디자인 참고 (Mobbin)

2026-10-10에 Aside 브라우저로 Mobbin에서 로그인 없이 볼 수 있는 [Switching Account 흐름](https://mobbin.com/explore/mobile/flows/switching-account)을 확인했다.

- Craft "Switching account": 아래쪽 Switch Account 목록에 계정 이름과 이메일을 두고 현재 계정에 체크를 표시한다. 목록 아래에 Add Account와 Settings가 있다. 적용: 현재 컴퓨터에 체크, 다른 컴퓨터는 이름 아래에 주소, 목록 아래에 **주소로 추가**.
- Instagram "Switching account": 목록에서 다른 계정을 누르면 확인 없이 바로 전환한다. 적용: 누르면 바로 이동하고, 다음 화면이 열리는 동안 그 항목에 진행 표시를 둔다.
- Spotify "Adding another account": 옆 메뉴 머리의 계정 영역에서 계정을 추가하고 전환한다. 적용: 휴대폰 메뉴 맨 위의 컴퓨터 이름을 전환 진입점으로 쓴다.
- 창 구성은 몽글의 기존 휴대폰 **터미널 전환** 창(목록 행, 아이콘, 현재 항목 체크)과 같게 맞췄다.

## 확인하지 않은 범위

- 실제 몽글 앱 화면에서의 조작과 실물 휴대폰에서 두 PC 사이를 오가는 흐름. 홈 화면에 추가한 앱에서 다른 주소로 넘어갈 때의 모양.
- Tailscale 접근 규칙으로 PC끼리 막힌 환경과 여러 사용자가 있는 tailnet.
- 목록에서 고른 PC가 이전 버전이면 그 PC 화면에는 전환 창이 없다. 설계상 동작이며 두 PC를 모두 업데이트해야 서로 오갈 수 있다.
