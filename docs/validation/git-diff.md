# Git 변경 비교(diff) 검증

기준일: 2026-10-12. 브랜치 `feat/git-diff-view`의 구현과 자동 검사 결과를 기록한다. **미배포 상태**이며 실제 Electron 앱·패키지·설치본 검증은 아직 하지 않았다.

## 설계와 참고

프로젝트 규칙에 따라 Mobbin 사례를 먼저 확인하려 했지만 **이번 작업에서는 확인하지 못했다.** Aside 브라우저의 Mobbin이 로그아웃 상태였고, 계정으로 로그인하는 동작은 자동 승인 검토에서 사용자 계정·인증 세션 접근 승인 근거가 없다는 이유로 거부됐다. 사용자에게 로그인 허용 여부를 따로 물었다. 화면 구성은 IntelliJ IDEA 비교 창에서 널리 알려진 방식(좌우 줄 맞춤, 다음·이전 변경 이동 F7/Shift+F7, 바뀌지 않은 구간 접기)을 기준으로 정했으며, 참고 화면을 직접 열어 대조한 것은 아니다. Mobbin 확인이 가능해지면 이 절을 갱신한다.

- 기존 파일 편집 영역의 탭으로 연다. 같은 파일도 스테이징 비교와 작업 중 비교는 탭 이름 옆 작은 표시(`스테이징`·`작업 중`·`HEAD 비교`)로 구분한다.
- 비교 도구 줄: **나란히 / 한 화면**, **변경 부분만**, 추가·삭제 줄 수, 현재 위치(`1 / 2`)와 이전·다음 변경. 경로 줄에는 **파일 열기**를 둔다.
- 색은 기존 Git 상태 색(추가 초록·삭제 빨강)을 그대로 쓰며 밝은·어두운 테마의 변수로 정의한다.
- 900px 미만 화면에서 처음 열면 **한 화면**으로 연다. 고른 방식은 이 브라우저에 기억한다.

## 구현 범위

호스트에 `git.diff` RPC와 capability를 추가했다. 기존 `git.status`와 같은 읽기 경로를 써서 연결·hostId·bootId·generation·현재 폴더를 I/O 전후에 확인하고 연결당 2개·전체 8개 읽기 한도를 공유한다.

- 비교 조합은 HEAD→스테이징, 스테이징→작업 폴더, HEAD→작업 폴더 세 가지만 허용한다. 스테이징 목록은 이름 변경 전 경로의 HEAD 내용과 비교한다.
- 저장된 내용은 `git cat-file`로 읽는다. textconv·smudge 필터를 쓰지 않아 저장소 설정의 외부 프로그램이 실행되지 않는다. 기존과 같이 셸 없이 고정 인자로 실행하고 선택적 잠금·fsmonitor·사용자 GIT 환경변수·지연 fetch를 끈다.
- 작업 폴더 파일은 직접 읽는다. 현재 폴더 밖을 가리키는 링크와 앱 데이터 폴더는 거부한다.
- 한쪽당 256 KiB까지 UTF-8(BOM 포함)·BOM이 있는 UTF-16 텍스트만 보낸다. 원격 연결의 송신 대기 한도(2 MiB)보다 충분히 작다. 바이너리·큰 파일·하위 모듈은 이유를 안내한다.
- 줄 끝(CRLF/LF)만 다른 경우 편집기가 줄 끝을 정규화해 차이가 보이지 않으므로 따로 안내한다.
- 화면은 CodeMirror 공식 확장 `@codemirror/merge` 6.12.2(MIT)를 사용한다. 비교 화면은 편집기 패널과 함께 지연 로드되며 앱 첫 화면 번들에 포함되지 않는다(빌드 결과에서 `FileEditorPanel` 청크에만 포함됨을 확인). 제3자 고지는 배포용 `runtime/node.exe` 기준으로 다시 생성했다.
- 비교 탭이 열려 있고 보이면 5초마다 다시 읽고, 내용이 바뀐 경우에만 화면을 다시 그린다.
- `git.diff`가 없는 이전 버전 호스트에서는 Git 목록의 파일을 누르면 지금처럼 현재 내용을 연다.

## 실제 수행

- `npm run typecheck`, `npm run build` 통과.
- 호스트 검사 `tests/host/git-diff.test.ts` 3개와 기존 `tests/host/git.test.ts` 6개, **9/9 통과**. 임시 폴더의 실제 Git 저장소에서 수정·스테이징 후 추가 수정·추가·삭제·한글 이름 변경·새 파일·하위 폴더 기준 경로·바이너리·크기 초과(작업 폴더·스테이징 양쪽)·CRLF·UTF-16을 확인했다. 인덱스 SHA-256 불변과, 설정한 smudge·textconv 필터와 fsmonitor가 실행되지 않음을 표시 파일로 확인했다. 폴더 밖 경로·앱 데이터·폴더 밖 링크·잘못된 비교 조합·추가 필드 거부도 확인했다.
- 화면 검사 `tests/ui/git-diff.test.ts`와 `tests/ui/git-explorer.test.ts`, **2/2 통과**. 실제 HostCore·Git·cmd 셸과 헤드리스 Chrome으로 나란히 보기, 바뀌지 않은 줄 접기, 이전·다음 버튼과 F7/Shift+F7, 한 화면 보기, 스테이징·작업 중 탭 분리, 이름 변경·삭제·새 파일(스크립트 미실행)·바이너리 안내, 파일 수정 후 자동 갱신, **파일 열기**로 편집 탭 열기, 밝은 테마, 390px 화면의 가로 넘침 없음, 셸 PID 유지를 확인했다. 기존 탐색기 검사는 `git.diff`가 없는 호스트의 이전 동작을 검사하도록 바꿨다. 화면 4개(`test-results/git-diff/`)를 직접 열어 확인했다.

## 확인하지 않은 범위

- Mobbin 사례 확인(위 설명 참고).
- 실제 Electron 개발 앱·패키지 앱에서의 조작, 아스트라 모델의 컴퓨터 유즈 검증, 실물 휴대폰의 원격 연결 화면.
- 전체 회귀 검사와 CI, 설치·업데이트 검사.
- 256 KiB를 넘는 파일의 비교, 스테이징·되돌리기 같은 Git 쓰기 작업(제공하지 않음), 파일 트리에서 바로 비교를 여는 동작(제공하지 않음).
