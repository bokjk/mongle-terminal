# 0.3.13 공개 배포 검증

## 배포 준비

2026-10-07. 사용자 요청으로 CLI 드래그 입력 보존·Shift 자동 복사와 모바일 전체화면 터치 스크롤을 0.3.13으로 배포 준비한다. 현재 공개 배포는 0.3.12이며 최종 게시·익명 다운로드 확인 전에는 배포 완료로 표시하지 않는다.

## 기능 검증

- 제품 코드 `ec5ac59`와 같은 최종 수정본 `1677690`의 전체 Windows CI: 회귀 452 통과·실패 0·선택 실행 15 생략, 별도 네이티브 클립보드·업데이트 브리지 2/2, 실제 NSIS 전체 파일 일치·교체·작업 복원 통과.
- [데스크톱 Claude 검사](claude-native-selection.md), [Codex 검사](codex-native-selection.md): 실제 몽글 앱의 드래그·복사. Claude 안내가 가린 글자 누락은 사용자에게 설명하고 허용된 알려진 제약으로 남겼다.
- [모바일 검사](mobile-cli-scroll.md): gpt-6-astra가 실제 Claude·Codex PTY에 연결해 Chrome 모바일 에뮬레이션의 trusted touch 양방향 이동, 포커스 유지, Codex Ctrl·Alt ON 스크롤을 확인했다. 실물 휴대폰 검사로 표현하지 않는다.
- 실사용 세션·인증·Tailscale Serve는 변경하지 않았다. 새 모델 요청 없이 합성 대화를 사용했다.

## 게시 전 확인

버전 PR·dev→main 배포 PR의 Windows 검사와 대상 정책을 확인한다. 최종 main 태그에서 회귀·패키징·네이티브·NSIS 실제 교체·복원을 통과한 windows-release artifact만 사용한다. 검증된 공개 초안의 5개 첨부와 메타데이터를 대조하고, 게시 뒤 인증 없는 전체 다운로드·해시와 실제 Electron 업데이트 다운로드를 확인한다.

## 남은 검증 범위

실물 휴대폰·OS 키보드·외부 Tailscale 네트워크 및 모든 CLI 버전은 전수 검사하지 않았다. 사용자와 합의한 모바일 검증 기준은 Chrome 모바일 에뮬레이션이다. Claude 자체 안내와 겹친 글자의 복사 누락은 남아 있다. 이 PC의 사용 중인 설치본은 배포 작업으로 자동 교체하지 않는다. 소스 비공개·라이선스·코드 서명 상태는 유지한다.
