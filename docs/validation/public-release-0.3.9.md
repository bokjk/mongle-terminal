# 0.3.9 응답성·안정성 배포 검증

기준일: 2026-10-04. **0.3.9 배포 준비 중**이다. 현재 공개 버전은 0.3.8이며, 아래 준비 기록은 공개 게시 완료를 뜻하지 않는다.

## 변경 범위

작은 터미널 출력 배치와 자동 캡처 중복 억제, 워크트리 Git 조회 병렬화·브랜치/태그 충돌 처리, 재연결·화면 상태·편집창 응답의 순서 보호, 탐색기 불필요한 읽기 취소를 포함한다. 출력 중 선택을 유지하고 데스크톱 복사의 실제 저장 결과를 확인하며 설정의 주소·연결 코드 복사 경로를 보완한다. [기능 검증](responsiveness-reliability.md), [클립보드 후속 수정](clipboard-followup.md)에 재현과 구현 근거가 있다.

## 배포 전 확인

- 준비 시작 시 `fix/responsiveness-and-reliability`의 `6fbb3b1`은 깨끗한 상태였고 원격 dev에 새로운 기능 변경이 없었다.
- 버전 변경 전 전체 회귀는 372개 중 357 통과·실패 0·선택 실행 15 생략이었다. 타입·빌드·패키지와 실제 접근 거부 UI 검사를 통과했다. 이 수치는 새 버전의 GitHub CI 결과와 별도로 기록한다.
- 로컬 도구에서는 Windows `OpenClipboard` 사전검사가 계속 오류 5를 반환한다. 권한을 우회하지 않고 독립 GitHub Windows 환경에서 정상 클립보드 E2E를 실행하도록 PR CI에 추가했다. 실패를 생략 처리하지 않는다.
- 태그 워크플로는 패키지 생성 후 실제 배포 EXE의 정상 클립보드와 업데이트 안내를 검사한다. 통과한 태그 빌드의 artifact를 배포 후보로 사용한다.
- 로컬 0.3.9 후보의 타입·빌드·문서 정합성·YAML·diff 검사, 배포/기여/브랜치 정책 회귀 31/31을 통과했다. 패키지 네이티브 의존성·7종 아이콘 검사도 통과했다.
- 실제 0.3.9 패키지의 출력 중 탐색·셸 유지, 종료 취소·정상 저장/종료·새 셸 복원, 업데이트 안내와 지원하지 않는 설치 요청 거부를 **3/3 통과**했다. 모든 시험 프로세스가 정리됐으며 NSIS 마법사 설치 검사는 아니다. 로그는 `test-results/release-039-packaged-e2e.log`다.
- 종료·복원 시험은 사용자 PowerShell 프로필·히스토리를 사용하지 않도록 기본 cmd `/d`로 바꿨다. 종료 취소 뒤 변수·PID 보존, 실제 종료·SQLite 상태, 새로운 셸의 변수 초기화·cwd 복원과 이전 명령 미재실행 확인은 유지했다.
- NSIS·ZIP·blockmap·업데이트 메타데이터·체크섬, PR/CI 병합, 공개 게시와 익명 다운로드 검증 결과는 실제 완료 후 이 문서에 추가한다.

## 첫 CI의 실패와 진단

[PR #33의 첫 최종 커밋 검사](https://github.com/bokjk/mongle-terminal/actions/runs/37192133276)는 `9838aaa`에서 타입·빌드·전체 회귀 **372개 중 357 통과, 실패 0, 선택 실행 15 생략**을 확인했다. 별도 네이티브 검사는 Windows 클립보드 사전검사에 성공했으나 앱이 실행부 연결 중인 상태에서 첫 화면의 기본 5초 대기가 끝났고, 격리 호스트 초기화도 확인하지 못했다. 이 실행은 실패이며 배포 통과로 사용하지 않는다.

실행부 시작과 인증·권한의 기본 회귀는 같은 CI에서 통과했다. 정상 클립보드 E2E에는 실제 연결 상태와 실행 오류 진단을 보강하고, 초기 준비 대기는 앱 시작 제한에 맞춰 별도로 지정한다. CI는 빌드 직후 네이티브 검사를 먼저 실행하여 이 경로의 실패를 조기에 확인하며, 성공한 뒤 전체 회귀도 모두 실행한다.

## 보호 범위와 한계

사용자 호스트·셸·인증 데이터와 실제 Tailscale Serve 설정을 변경하지 않는다. 네이티브 시험은 TEMP의 고유 프로필에 격리한다. 공개 저장소에는 사용자 안내와 배포 산출물만 게시하며 소스 공개 범위·라이선스를 바꾸지 않는다. 기존 0.3.8 첨부 파일을 다른 바이너리로 덮어쓰지 않는다.

설치 파일 생성·해시 검증, 업데이트 다운로드, 작업 공간 정상 종료·복원은 각각의 검사 범위다. 실제 사용자 설치본 교체와 NSIS 설치 마법사 전체 조작을 그 성공으로 간주하지 않는다.
