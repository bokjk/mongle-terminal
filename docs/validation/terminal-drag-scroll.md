# 긴 터미널 출력의 드래그 선택

후속 상태: 이 변경은 2026-10-06에 0.3.12로 공개했다. 아래 내용은 개발 당시의 검사 기록이며, 최종 태그·설치·공개 다운로드 결과는 [배포 기록](public-release-0.3.12.md)을 따른다.


2026-10-06. 개발 브랜치 `codex/terminal-drag-selection`; 미배포 변경이다.

## 원인과 수정

전체 호스트 프레임을 표시할 때 `terminal.reset()`은 xterm의 문서 드래그 리스너와 자동 스크롤 타이머를 해제한다. 기존 코드는 선택 모델과 리스너를 복원했지만, 매번 50ms 타이머를 새로 시작했다. 더 빠른 프레임이 계속 오면 타이머가 실행되지 않아 화면 밖으로 드래그해도 선택 범위를 늘리지 못한다.

고정 의존성 xterm 6.0.0의 선택 서비스 어댑터에서 다음 스크롤 예정 시각을 함께 보존한다. 프레임을 처리하는 동안에는 스크롤하지 않고 완성된 버퍼와 선택을 복원한 뒤 남은 대기 시간부터 재개한다. 밀린 시간만큼 여러 번 따라잡지 않는다. 새 마우스 제스처는 이전 타이머와 구별하며, 마우스 해제·입력에 의한 취소·선택 내용 변경·폐기 시 기존 취소 절차를 따른다. 화면 구성이나 새 선택 모드는 추가하지 않았다.

## 실제 확인

- Aside의 격리된 브라우저 화면에서 실제 `BrowserPresentationAdapter`와 xterm을 사용했다. 120줄을 표시한 뒤 위쪽 밖으로 드래그하고 8ms 간격을 둔 전체 프레임 40개를 적용했다. 수정 전 viewport는 102에서 102로 멈췄고, 수정 후 동일한 동작은 112에서 0까지 이동했다. 아래 방향도 0에서 112까지 이동했다.
- 실제 React `TerminalPane`을 묶은 별도 시험 화면에서 한글·영문 120줄을 사용했다. 출력 갱신 중 위·아래 방향 선택과 출력이 멈춘 상태의 아래 방향 선택에서 복사 요청 문자열이 120줄 원문과 정확히 일치했다. 각 제스처는 한 번만 복사했고 터미널 입력 전송은 0건, 오류는 없었다.
- 프레임 완료 콜백을 보류한 동안 자동 스크롤은 진행하지 않았다. 그 사이 마우스를 놓은 뒤 완료를 재개하면 복사는 한 번, 복사 문자열과 최종 선택 내용은 일치하고 이후 viewport도 이동하지 않았다.
- 복원된 자동 스크롤이 동작하는 중 `x`를 입력하면 선택과 타이머가 취소됐고, 이전 선택 복사는 0건이며 입력은 `x` 한 번만 전달됐다.
- 브라우저 시험은 실제 선택·화면 갱신·React 자동 복사 핸들러를 사용했다. 호스트 전송과 클립보드 쓰기 경계는 시험 대역이다. 실제 Windows 클립보드 쓰기나 설치된 Claude/Codex에 로그인해 대화를 진행한 검사는 아니다.

## 자동 검사

- `runtime/node.exe node_modules/typescript/bin/tsc --noEmit`: 통과.
- `runtime/node.exe --import tsx scripts/build.ts`: 웹·호스트·데스크톱 빌드 통과. 기존 500kB 청크 크기 경고는 남아 있다.
- `runtime/node.exe --import tsx --test --test-concurrency=1 tests/terminal/engine.test.ts tests/terminal/input-queue.test.ts tests/terminal/history-restore.test.ts tests/ui/terminal-input-queue.test.ts`: 55 통과, 실패·생략 0. 이 기존 명령에는 Chrome을 직접 실행하는 `tests/terminal/input-queue.test.ts`가 포함되어 있었다. 해당 실행 후 추가 화면 검사는 Aside로 진행했다.
- `tests/terminal/browser.test.ts`에 연속 프레임 중 위·아래 선택 스크롤 및 해제 후 타이머 종료 회귀 2개를 추가했다. 새 테스트 파일의 Chrome 실행은 로컬에서 하지 않았으며, 동일한 재현 동작을 Aside에서 확인했다.
- `runtime/node.exe --import tsx scripts/release-check.ts`, `git diff --check`: 통과.

## 남은 범위

이 수정은 재현된 자동 스크롤 정지 원인을 다룬다. CLI가 선택된 줄 자체를 다른 내용으로 덮어쓰는 경우, 보관 한도를 넘어 사라진 과거 출력, 모바일 터치 선택은 이 검사에서 해결됐다고 보장하지 않는다. 잘못된 다른 글을 복사하지 않도록 변경된 선택 내용은 기존처럼 해제한다. 새 패키지 설치·배포·실사용자 확인은 아직 하지 않았다.
