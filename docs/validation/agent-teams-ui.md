# AI 팀 화면

2026-10-15, Windows x64. **0.3.24 배포 준비** 상태다. 배포 검사는 [0.3.24 배포 검증](public-release-0.3.24.md)에 기록한다. AI 팀 기능 2단계의 화면 부분이다([설계안](../08-agent-team-design.md), 실행부는 [AI 팀 실행 (호스트)](agent-teams-host.md)). 사용자는 왼쪽에서 팀을 시작하고, 팀 화면에서 구성원 터미널을 보며, 팀 대화로 팀장이나 구성원에게 메시지를 보낸다. 구성원끼리 직접 보내는 기능은 3단계다.

## 동작

- **시작:** 사이드바 **프로젝트 열기** 아래 **AI 팀으로 시작**, 또는 **AI 팀** 구역의 `+`. 그룹이 없으면 누를 수 없다.
- **팀 구성:** 작업할 그룹(작업 폴더는 그룹의 폴더), 팀 이름(템플릿 이름이 기본값), 템플릿 카드, 구성원 표. 별표로 고른 기본 템플릿은 기기에 저장한다(`mongle.team.defaultTemplate`). 역할을 바꾸면 사용자가 지시문을 고치지 않았을 때만 그 역할의 지시문으로 바꾸고, 읽기 전용은 역할 기본값을 따른다. 이름을 바꾸면 그 이름에 보고하던 구성원의 보고 대상도 따라간다. 구성원을 빼면 그 구성원에게 보고하던 사람은 팀장(팀장이 빠지면 사용자)에게 보고한다. 문제(이름 겹침, 보고 대상 없음 등)는 실행부와 같은 `teamProblems`로 즉시 보여 주고 다음 단계를 막는다. 모델 칸은 직접 쓰며, Claude 별칭(`opus`·`sonnet`·`haiku`)과 템플릿에 쓰인 모델을 제안한다.
- **템플릿으로 저장:** 시작 창의 구성원 표 아래, 팀 화면 맨 아래 줄. 지금 고른 내 템플릿과 이름이 같으면 그 템플릿을 고친다. 기본 템플릿은 새 템플릿이 된다.
- **시작 전 점검:** `teams.check` 결과를 줄마다 통과·주의·해결 필요로 보여 준다. 오류가 있으면 **팀 시작**을 막는다. **다시 확인**으로 다시 묻는다.
- **팀 화면:** 그룹의 분할 배치 대신 팀 배치를 쓴다. 팀장 터미널이 왼쪽(약 63%), 나머지 구성원이 오른쪽에 세로로 쌓인다(각각 최소 150px, 넘치면 스크롤). 구성원 터미널은 탭 머리줄 대신 이름과 배지(팀장 또는 역할, 도구·모델, 읽기 전용)를 보여 준다. 최대화하면 그 구성원만 보인다. 팀 화면에서는 패널 끌어 놓기를 끈다.
- **휴대폰 너비(700px 이하):** 이번 단계에서는 AI 팀으로 시작 버튼, AI 팀 구역, 팀 화면을 보여 주지 않는다. 구성원 터미널은 그룹의 일반 탭으로 보이고 기존 메시지 보내기를 쓸 수 있다. 처음에는 좁은 화면에서도 팀 화면을 보여 주려 했으나, 320×480 사이드바에 팀 구역이 들어가 워크트리 메뉴 위치 회귀 시험이 실패해 휴대폰 화면은 4단계로 미뤘다.
- **팀 대화:** `teams.message`(실행부)가 받는 구성원의 보류함에 `[몽글 팀 메시지] 사용자 → 이름` 머리글을 붙여 넣는다. 전달 조건은 에이전트에게 메시지와 같다. 보류함이 메시지를 내보내면(Enter까지 보냄), 취소되면, 보내지 못하면(붙여넣기 뒤 셸로 돌아감, 터미널 종료, 실행부 종료) 실행부가 그 결과를 팀 기록에 남긴다. 기록은 팀마다 최근 100개, 미리보기는 200자다. 실행부가 다시 시작할 때 기다리던 메시지는 보류함이 메모리에만 있어 사라졌으므로 "전달하지 못함"으로 바꾼다. 기다리는 메시지는 보류함의 대기 이유를 그대로 보여 주고 `X`로 취소한다(`agent.message.cancel`).
- **사이드바:** **AI 팀** 구역에 팀과 상태 배지, 열린 팀의 구성원(팀장 왕관, 도구·모델, 시작하지 못함·터미널 닫힘). 작업 그룹을 누르면 일반 분할 화면으로 돌아간다. 마지막으로 연 팀은 기기에 기억한다(`mongle.team.<hostId>`). 휴대폰 알림을 눌러 팀 구성원 터미널로 오면 팀 화면을 연다.
- **팀 해제:** 맨 아래 줄 `···` → **팀 해제…**. 확인 뒤 `teams.remove`로 팀 기록·대화·지시문 파일을 지운다. 터미널과 CLI는 남는다.
- 실행부가 `agent.teams` 기능을 알리지 않으면(이전 버전) 버튼과 구역을 보여 주지 않는다.

**고친 것:** 보고 대상을 이름 대신 구성원 줄 기준으로 기억한다. 팀 화면의 터미널 이름은 구성원 이름만 쓰고 분할·워크트리·닫기 버튼과 머리줄의 제어 상태 글자(패널 아래 줄에도 있음)를 빼며, 읽기 전용은 자물쇠 아이콘으로 줄였다. 패널 너비가 360px 이하이면 모델 배지에서 도구 이름과 검색 버튼을 숨긴다. 창 너비 1180px 이하에서는 구성원을 팀장 아래 줄로 내린다. 준비 안내는 도구별로 쓴다. 쓰던 글은 창을 닫기 전까지 팀마다 남긴다. 팀 메뉴는 위로 연다. 보류함은 보류 사유가 그대로여도 메시지를 더하거나 취소할 때마다 요약을 갱신한다(1단계 메시지 배너의 개수가 늦게 바뀌던 같은 원인). 보류함 단위 시험 1개와 화면 시험 문구를 더했다.
