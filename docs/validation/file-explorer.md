# 공용 파일 탐색기 검증

기준일: 2026-09-30. 0.3.2 배포에 포함하는 기능이다. 공개 게시 상태는 [0.3.2 배포 검증](public-release-0.3.2.md)을 확인한다.

## 구현

오른쪽 패널 하나가 화면에서 마지막으로 선택한 터미널의 `currentCwd`(없으면 시작 cwd)를 따른다. 인증된 기존 RPC 연결로 선택한 호스트의 파일을 읽는다. `files.read` capability가 없는 이전 호스트에는 업데이트 안내를 표시한다. 파일 탐색은 제어권·셸 경로·그룹 배치를 변경하지 않는다.

호스트의 파일 I/O는 터미널 입력·heartbeat·저장 작업 큐와 분리했다. 연결당 2개·호스트 전체 8개 조회로 제한하고, I/O 전후에 연결 객체·기기·hostId·bootId·generation·현재 폴더를 재검사한다. 화면은 터미널·호스트·폴더 변경 시 기존 결과를 버리고 미리보기 응답의 순서를 검사한다.

목록 500개, 텍스트 64 KiB 제한. 경로 정규화와 realpath로 폴더 밖 이동·링크 이탈을 차단한다. Windows 장치 경로·ADS·UNC와 호스트 데이터 폴더를 거부한다. 파일 내용은 React 텍스트로 출력하며 실행하지 않는다.

## 실제 수행

- 타입 검사와 웹·호스트·데스크톱 빌드 통과.
- 배포 문서 검사(`node --import tsx scripts/release-check.ts`)와 `git diff --check` 통과. 기능 검사 당시 버전은 0.3.1이었으며 이후 0.3.2 배포를 준비했다.
- 파일 검사 3/3 통과: 한글·UTF-16·큰 파일·바이너리·목록 한도, 경로 이탈·junction·인증 데이터 보호, 원격 기기 맥락·오래된 참조·동시 읽기 제한·연결 폐기 후 응답 차단.
- 실제 HostCore와 Chrome 화면 검사 통과: 4개 터미널의 공용 패널, 폴더 펼치기·텍스트 미리보기·HTML 미실행·경로 복사·선택 터미널 변경·늦은 응답 거부·새로고침·너비 조절·실제 cmd `cd` 추적·테마·모바일 표시·Escape 닫기·기존 셸 PID 유지. 검사는 TEMP의 새 폴더만 사용했다.
- 기본 전체 회귀 291개 중 280개 통과, 실패 0개, 조건부 11개 건너뜀. `npx tsx --test --test-concurrency=1 tests/**/*.test.ts`로 실행했다. 이후 Escape 닫기 추가는 다시 빌드하고 파일 탐색기 화면 검사를 재실행해 통과했다.
- 실제 WebSocket 게이트웨이에서 미인증 파일 RPC 거절과 페어링된 요청 전달을 검증했다. 이 검사의 HostCore는 테스트 더블이며, 실제 HostCore의 원격 기기 맥락 검사는 별도 파일 RPC 검사에서 수행했다.
- TEMP의 별도 프로필과 샘플 프로젝트로 개발 Electron 창을 실행했다. 터미널 4개의 생성·데스크톱 연결·실제 OwnerPipe를 통한 파일 목록 조회를 확인했다. 사용자 육안 확인은 아직 완료로 간주하지 않는다.
- 생성 화면은 `test-results/file-explorer/`에 보관하고 개인 경로가 표시될 수 있어 커밋하지 않는다. 실제 인증 데이터·기존 호스트·Tailscale 설정을 변경하지 않았다.

실물 모바일·다른 PC의 Tailscale 연결·설치 패키지 배포는 이번 작업에서 검증하지 않았다. 모바일 결과는 Chrome 뷰포트 검사이며, 공개 설치본의 업데이트 완료를 의미하지 않는다.
