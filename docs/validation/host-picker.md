# 컴퓨터 선택 메뉴 개선 검증

2026-09-30. 0.3.3에 포함하는 UI 변경이다. 게시 상태는 [배포 검증](public-release-0.3.3.md)에 별도로 기록한다.

운영체제 기본 select 목록을 앱 테마의 버튼·listbox로 바꿨다. 목록 최소 폭 280px(작은 화면에서는 뷰포트 안으로 제한), 항목 높이 60px, 컴퓨터 종류 아이콘·보조 설명·선택 체크 표시를 적용했다. 긴 이름은 말줄임과 전체 이름 툴팁으로 표시한다.

방향키·Home/End는 후보만 이동하고 Enter·클릭으로 확정한다. Escape·바깥 클릭으로 취소하고 Tab으로 나갈 수 있다. 메뉴의 활성 항목과 선택 상태를 ARIA로 구분한다. 현재 컴퓨터 재선택은 연결을 초기화하지 않는다. 기존 호스트 연결 RPC와 터미널 제어권 정책은 바꾸지 않았다.

## 실제 검증

- 타입 검사·웹/호스트/데스크톱 빌드 통과.
- `tests/ui/host-picker.test.ts`: 실제 Chrome에서 PC 1개/3개/33개, 긴 이름, 밝은/어두운 테마, 320px 화면, 목록 크기와 스크롤, 선택/재선택, 방향키·Home/End·Enter·Escape·Tab, 바깥 클릭과 포커스 복귀 통과. 호스트 연결은 테스트 더블이며 외부 PC에는 접속하지 않았다.
- `tests/ui/pane-drag.test.ts`: 실제 HostCore와 Chrome의 분할·교환·생성·취소·입력/제어권 유지·저장 복원 회귀 통과. 기존 native select 자동화는 새 메뉴에 맞췄다. 네이티브 드래그는 물리 클릭/키 입력을 억제하므로 드래그 도중 호스트 전환 경계는 기존 그룹 전환 검사와 같이 DOM 활성화로 주입했다. 일반 클릭/키보드 전환은 위 전용 검사에서 별도로 검증했다.
- 화면 캡처는 개인 경로가 없는 테스트 PC 이름으로 `test-results/host-picker/`에 보관한다. 실제 사용자 프로필·인증 정보·기존 실행 호스트를 변경하지 않았다.

화면 검사는 브라우저 기반이다. 스크린리더 실기, 실물 모바일, 새 설치 패키지 적용·배포는 검증하지 않았다.
